# BOBO 機器人衍生圖 — ChatGPT 4o 用 Prompt 包

你有主視覺了。下面 5 個變化版都用同一個流程生：

## 操作流程（每張都這樣）

1. 在 [chat.openai.com](https://chat.openai.com) **新開一個對話**（避免上一張的 context 污染）
2. **上傳你的主視覺圖**（用迴紋針或拖拉進去）
3. 貼下面對應變化的 prompt（已含「保持同角色」指令）
4. 等 1-2 分鐘 → 右鍵下載 PNG → 重新命名 → 放到 `/Users/lunch/知識筆記/注音遊戲/assets/`

⚠️ 重要：**每張都重新開對話** — ChatGPT 4o 在同一對話裡連續生圖會逐漸漂移（角色變樣）。

---

## ① 答對開心版 → `robot-bobo-happy.png`

```
I'm attaching a reference image of my robot mascot. Generate a new image
with the EXACT same character — identical shape, colors, eyes, antenna,
body, proportions, and 2D vector art style.

Only change the pose and expression:
BOBO is jumping up joyfully. Both arms raised high in the air, mouth wide
open in a big cheerful smile, eyes squinted into happy ^^ shapes. Add
small motion lines below the feet to suggest jumping. Dynamic celebratory
pose.

Keep solid white background. Square 1:1. No text. Centered.
```

## 完成後

把全部 6 張（基本 + 5 變化）放好後跟我說「圖都好了」，我會：
1. 改 `index.html` — 把目前內嵌的 SVG 機器人換成 `<img>` 標籤
2. 加 fallback：找不到 PNG 就用 SVG（這樣沒生圖的人也能玩）
3. 在對應情境換圖：
   - 平常 → `robot-bobo.png`
   - 答對 → 短暫切到 `robot-bobo-happy.png` 再回平常
   - 答錯 → 短暫切到 `robot-bobo-sad.png` 再回平常
   - 等聽喇叭 → `robot-bobo-thinking.png`（可選）
   - 過 Stage 1 → 之後平常版改成 `robot-bobo-stage1.png`
   - 過 Stage 2 → 之後平常版改成 `robot-bobo-stage2.png`
   - 過 Stage 3 → 之後平常版改成 `robot-bobo-king.png`
4. preview 截圖確認
