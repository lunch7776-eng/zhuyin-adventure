## 冒險地圖（adventure.html）設計理念

原版適合自由探索；冒險地圖補上「一條引導路線」：

1. **零閱讀門檻** — 所有指令念出來、按鈕用大圖示，不靠文字導航
2. **一條路** — 12 座島嶼串成冒險地圖，BOBO 站在哪就玩哪，永遠知道下一步
3. **教 → 練 → 測 微循環** — 每座島固定三關：
   - 🐣 **認識**：一次一個新注音，聽發音＋例字、描筆順；🎤「換你念」會**真的錄下孩子的聲音放給他聽**，再播一次正確發音對照（瀏覽器要允許麥克風；拒絕的話退回「跟著念」提示模式）
   - 🎮 **遊戲**：戳泡泡 / 餵BOBO / 翻牌配對，三種小遊戲輪流
   - ⭐ **挑戰**：聽音選字拿星星，全對 3 顆星，過關送整島貼紙＋徽章
4. **錯了不罰** — 答錯時 BOBO 再示範一次、讓孩子重選；錯的字進「複習袋」
5. **間隔複習** — 複習袋的字會自動出現在之後挑戰關的開頭（🎒 複習時間）
6. **收集慾** — 📒 貼紙書收集 58 個注音貼紙＋12 個島嶼徽章，點貼紙可重聽發音

## 給家長

- **每天 1-2 關（5-10 分鐘）就停**，隔天再來 — 比一次玩半小時有效
- 答錯時不用糾正，遊戲會自己示範＋安排複習
- 過關獎勵用實體的（貼紙、選晚餐）比螢幕裡的星星更有效
- 不用螢幕的小練習（家長角落裡也有）：
  - **送氣偵測**：面紙放嘴前 — 念ㄅ不會飄、念ㄆ會飄
  - **鼻音偵測**：捏住鼻子 — ㄇ/ㄋ念不出來，ㄅ/ㄉ沒影響
  - **照鏡子**：舌頭翹起來是ㄓㄔㄕ、平貼下牙是ㄗㄘㄙ

| 內容 | 來源 |

| 37 個基本注音（ㄅ~ㄩ） | ✅ 教育部官方 WAV 錄音（CC BY 4.0） |
