# 注音大冒險 🌈

給 6-7 歲、注音「認得幾個但會混」的小孩，每次 5-10 分鐘的瀏覽器小遊戲。

兩種使用方式：

1. **📖 注音字典（自由探索模式）** — 首頁橘色大按鈕。所有 58 個注音（21 聲符 + 16 韻符 + 21 結合韻）一頁顯示，點任何一個聽教育部錄音 + 例字。不計分、不闖關。小孩剛起步時先逛這裡。
2. **🌈 闖關模式** — Lv1 雙唇音 → Lv2 聽音辨字 → Lv3 結合韻拼字。會給星星跟解鎖。

## 怎麼玩

雙擊 `index.html` 用瀏覽器（建議 Chrome / Safari）打開即可。
無需網路、無需安裝、進度自動存在本機。

如果聽不到聲音 → 瀏覽器分頁可能被靜音，點分頁圖示解除靜音。

## 關卡設計理念：依「發聲學難度」分級

不是按注音表的順序（ㄅㄆㄇㄈ→ㄉㄊㄋㄌ…），而是按「小孩的口腔能不能做出這個音」排序。

### Lv1 · 嘴型偵探（雙唇音 + 唇齒音）

| 注音 | 例字 | 怎麼做 | 為什麼放在第一關 |
|------|------|--------|------------------|
| ㄅ | 爸 | 嘴閉緊 → 爆開 | 雙唇音，小孩看得到嘴型 |
| ㄆ | 皮 | 嘴閉緊 → 爆開 + 送氣 | 跟 ㄅ 對立，練送氣 |
| ㄇ | 媽 | 嘴閉著哼鼻 | 鼻音，從鼻腔出來 |
| ㄈ | 飛 | 上齒咬下唇 | 唇齒音，看得到動作 |

過關標準：5 顆星。

### Lv2 · 聽音找朋友（聲符全集 + 易混組強化）

按發聲學分組出題，從「差很多的」漸進到「最會混的」：

1. **暖身組**（差很多）：ㄅ／ㄉ／ㄍ、ㄇ／ㄋ／ㄌ
2. **送氣對立**：ㄅ／ㄆ、ㄉ／ㄊ、ㄍ／ㄎ、ㄐ／ㄑ、ㄗ／ㄘ、ㄓ／ㄔ
3. **翹舌 vs 平舌**（國台語家庭最容易混）：ㄓ／ㄗ、ㄔ／ㄘ、ㄕ／ㄙ
4. **鼻音 vs 邊音**：ㄋ／ㄌ
5. **顎化音對齊**：ㄐ／ㄓ、ㄑ／ㄔ、ㄒ／ㄕ

過關標準：6 顆星。

### Lv3 · 拼字小工匠（韻符 + 結合韻）

看圖（蘋果🍎、月亮🌙、西瓜🍉、雨傘☂️、魚兒🐟、花朵🌸、牛奶🥛、蛋糕🎂）→
從注音池選對的韻 / 結合韻填空。

涵蓋：
- 單韻 ㄚㄛㄜㄝ
- 複韻 ㄞㄟㄠㄡ
- 鼻韻 ㄢㄣㄤㄥ
- 結合韻 ㄧㄚ / ㄧㄝ / ㄧㄠ / ㄧㄡ / ㄧㄢ / ㄧㄤ / ㄧㄥ / ㄨㄚ / ㄨㄛ / ㄨㄢ / ㄨㄣ / ㄨㄤ / ㄨㄥ / ㄩㄝ

過關標準：5 顆星。

## 給家長：怎麼搭配遊戲幫小孩學

**每天玩一關就好**，6-7 歲的注意力 5-10 分鐘最有效。玩完當天就停，隔天再來。

**會混的不要急著糾正**：
- 系統會自動把易混組混在一起出題（例如 ㄅ／ㄆ 一定會在 Lv2 連續遇到）
- 答錯時，遊戲會自動再念一次正確答案，不會罵
- 你在旁邊可以陪念，不要直接告訴他答案

**過關獎勵建議**：
- Lv1 過關 → 一張貼紙
- Lv2 過關 → 選晚餐
- Lv3 過關 → 親子活動（去公園、看電影）

實體獎勵比螢幕內的星星更有效。

**進階自製練習**（不用遊戲也能玩）：
- 「送氣不送氣」：拿一張面紙放嘴前，念 ㄅ 不會飄、念 ㄆ 會飄 — 讓他自己用手感受
- 「鼻音偵測」：捏住鼻子念 ㄇ／ㄋ → 念不出來；念 ㄅ／ㄉ → 沒影響
- 「翹舌 vs 平舌」：照鏡子，舌頭翹起來看得到就是 ㄓㄔㄕ；舌頭平貼下排牙就是 ㄗㄘㄙ

## 聲音設定（台灣口音、年輕男女）

右上角 ⚙️ 齒輪按鈕打開，可以：

1. **切換性別**：女生 / 男生
2. **看系統有哪些 zh-TW 聲音**（從你電腦的 voice 庫挑）
3. **試聽每個聲音**：找出聽起來最年輕的那個

### 不同系統有不同選擇

| 系統 / 瀏覽器 | 預設台灣聲音 | 備註 |
|---|---|---|
| macOS Safari | 美佳（女） | 系統內建，**沒有男聲台灣 voice** — 男生模式會用降低音調模擬 |
| iOS Safari | 美佳 / 美嘉（女） | 同上 |
| Chrome (Mac/Win) | Google 國語（臺灣） | 通常有男聲（需網路），會多很多 voice 選項 |
| Edge | Microsoft HsiaoChen / HsiaoYu | **Microsoft 有男生台灣聲音** YunJhe，是想要真實男聲的最佳選擇 |

**想要真實年輕男聲** → 建議用 Edge 瀏覽器開，或 Chrome 開啟雲端 voice。

### 年輕音色怎麼做出來的

不是換配音 — 是用 `pitch` 把聲音調往年輕方向：
- 女生模式：pitch = 1.3（比原始女聲略高，聽起來像 20 歲女大生）
- 男生模式：pitch = 0.65（沒有男聲時把女聲大幅降低音調，會有點電子味但能跟女聲區分）
- 若系統有真男聲：pitch = 1.05（年輕大學生男生）
- 語速 0.85（教學用，比正常慢一點點，小孩聽得清楚）
