# 機器人 BOBO 圖像生成 Prompt

當你拿到 OpenAI API key 後，跟 Claude 說「生機器人圖」即可觸發。
也可以自己貼進 ChatGPT 4o image gen 介面用。

## 主視覺 Prompt (用於首頁入口 / 主機器人)

```
A cute friendly cartoon robot mascot named BOBO for a children's
Mandarin Phonetic Alphabet (Bopomofo / Zhuyin) learning game.
Round head with a single antenna with a glowing orange light bulb on top,
big black-and-white shiny eyes with cheerful expression, a small smile.
Body is a rounded soft cube with a small screen on the chest showing a
yellow lightning bolt (⚡). Two stubby arms and two short legs.
Color palette: sky blue head, mint green body, orange antenna,
white face. Soft pastel shading, thick clean outlines, 2D vector style,
chibi proportions, plain white background, centered, no text, no shadow.
Style: modern children's book illustration, friendly and approachable,
suitable for ages 5-8. Square 1:1 aspect ratio.
```

→ 輸出檔名建議：`assets/robot-bobo.png`，512×512，PNG with transparency

## 升級階段變化（4 個版本）

### Stage 0：基本版（剛開始）
（同上主視覺 prompt）→ `assets/robot-bobo-0.png`

### Stage 1 通關：加金色光環
```
(基本版 prompt) + holding a tiny zhuyin character "ㄅ" on one hand,
with a golden glowing halo floating above its antenna.
```
→ `assets/robot-bobo-1.png`

### Stage 2 通關：加披風
```
(基本版 prompt) + wearing a small red superhero cape behind it,
holding two zhuyin characters, golden halo above head.
```
→ `assets/robot-bobo-2.png`

### Stage 3 通關：戴皇冠（注音王）
```
(基本版 prompt) + wearing a small golden crown on top of antenna,
red cape flowing, body glowing with rainbow sparkles, holding multiple
zhuyin characters around it, looking triumphant. Background: subtle
sparkle bokeh effect (still transparent or off-white).
```
→ `assets/robot-bobo-3.png`

## 表情變化（同基本造型，換表情）

```
(基本版 prompt) + currently jumping joyfully, arms up, mouth open in
a happy smile, eyes shaped like ^^ closed in joy.
```
→ `assets/robot-bobo-happy.png`

```
(基本版 prompt) + looking confused, slight frown, eyes looking sideways,
head tilted, small sweat drop on forehead.
```
→ `assets/robot-bobo-sad.png`

## OpenAI gpt-image-1 API 呼叫範例

```bash
curl https://api.openai.com/v1/images/generations \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-1",
    "prompt": "<上面的 prompt 全部貼進來>",
    "size": "1024x1024",
    "quality": "high",
    "background": "transparent",
    "n": 1
  }' | jq -r '.data[0].b64_json' | base64 -d > assets/robot-bobo.png
```

每張圖約 USD$0.04（high quality）/ $0.02（medium）。
6 張全套約 USD$0.25。
